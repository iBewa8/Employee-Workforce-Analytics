📊 مشروع تحليل القوى العاملة (HR Employee Workforce Analytics)
 نبذة عن المشروع
تم تطوير لوحة بيانات (Dashboard) تفاعلية بالكامل باستخدام برنامج Excel لتحويل بيانات الموظفين الخام إلى مؤشرات ورسوم بيانية تساعد في فهم هيكل القوى العاملة وتسهيل اتخاذ القرار.
 الأدوات المستخدمة
Microsoft Excel: تم استخدام الجداول المحورية (Pivot Tables)، أدوات التصفية السريعة (Slicers)، والرسوم البيانية المتقدمة (Dashboards) لتنظيم وعرض البيانات
 التحليلات والمؤشرات التي تم تنفيذها
مؤشرات الأداء الرئيسية (KPIs): احتساب إجمالي الموظفين، إجمالي التعويضات والرواتب، متوسط التعويض لكل موظف، متوسط تقييم الأداء العام، ونسبة الموظفين بدوام كامل
تحليل التوزيع حسب الأقسام (Employee by Department): قياس وتوزيع عدد الموظفين على الأقسام المختلفة مثل التصنيع، التسويق، وتطوير المنتجات.
تحليل اتجاهات التوظيف (Hiring Trend): تتبع معدلات وحركات التوظيف خلال الفترات الزمنية.
تحليل الأداء (Job Rating Distribution): تصنيف وتقييم درجات أداء الموظفين5.
تحليل الحالات الوظيفية والمزايا (Employee by Status & Benefits): دراسة نسب الموظفين حسب نوع الدوام (دوام كامل، جزئي، عقود) وباقات المزايا الوظيفية المقدمة لهم.
تحليل التوزيع الجغرافي (Employee by Building): توضيح توزيع الموظفين ونسبهم على المباني والمواقع المختلفة
التفاعل الديناميكي (Slicers): ربط كافة التحليلات بأزرار تصفية جانبية تتيح فرز البيانات فورياً حسب القسم أو حالة التوظيف أو الموقع
